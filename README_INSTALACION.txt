CMH CRM Profesional - Fases restantes integradas

INSTALACIÓN EN HOSTINGER

1. En Hostinger crea una base de datos MySQL:
   hPanel > Bases de datos > MySQL.

2. Sube esta carpeta al hosting:
   public_html/crm/

3. Copia config.example.php y renómbralo como config.php.

4. Edita config.php con los datos de MySQL que te da Hostinger:
   db_name, db_user, db_pass.

5. Abre:
   https://mueblescocinasyclosets.com/crm/install.php

6. Crea el usuario administrador.
   Sugerido:
   admin@cmhproyectos.com
   admin123

7. Después entra a:
   https://mueblescocinasyclosets.com/crm/login.php

8. Por seguridad, después de instalar elimina install.php.
