# CMH CRM - Sprint 1

Base profesional inicial en PHP + MySQL para Hostinger.

## Incluye
- Instalador
- Login
- Dashboard
- Clientes
- Prospectos
- Seguimientos básicos
- WhatsApp directo

## Instalación rápida en Hostinger
1. Sube todos los archivos al repositorio `cmh-crm`.
2. En Hostinger crea una base de datos MySQL.
3. Copia `config.example.php` como `config.php`.
4. Edita `config.php` con los datos de MySQL.
5. Abre `https://tudominio.com/crm/install.php`.
6. Entra con:
   - Usuario: `admin@cmhproyectos.com`
   - Contraseña: `admin123`
7. Elimina o renombra `install.php` por seguridad.
